# ML-OPS-CI-CD — навчальний репозиторій

Цей репозиторій містить домашні завдання курсу **ML-OPS / CI-CD**.

## Завдання

### Урок 3 — Контейнеризація ML-моделей *(перше завдання курсу)*

TorchScript-експорт моделі `mobilenet_v2`, inference-сервіс на Python та два
Docker-образи (fat vs multi-stage slim) з докладним порівнянням.

Усі матеріали — у каталозі [`lesson-3/`](lesson-3/):

- 📋 **[`lesson-3/TASK.md`](lesson-3/TASK.md)** — повний опис домашнього завдання:
  мета, кроки виконання, вимоги до структури та критерії оцінювання. У секції
  «Критерії оцінювання» біля кожного пункту вказано, у якому файлі/рядку він
  реалізований.

- 🚀 **[`lesson-3/README.md`](lesson-3/README.md)** — коротка інструкція для
  перевіряючого: передумови, як зібрати обидва Docker-образи, як запустити
  inference на вкладеному `sample.jpg` або на власному зображенні, як прогнати
  host-setup скрипт.

- 📊 **[`lesson-3/REPORT.md`](lesson-3/REPORT.md)** — звіт-порівняння
  fat (2.75 GB) vs slim (692 MB): таблиці розмірів і шарів, розбір проблем
  «жирного» образу, список оптимізацій, що дали економію ~2 GB, і подальші
  напрямки (distroless, CPU-only wheel, LibTorch, квантизація тощо).
